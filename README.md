One out-of-office auto-reply from an AI agent that quit its job to pull
espresso shots — machine habits turned to coffee, in a single line.

## Run

```sh
node main.ts
```

Writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (defaults to
`/output/entry.txt`), after self-validating the gate: one line,
1–280 characters, no trailing newline.
